🎯 Next Steps

1. Install Dependencies
cd chat && pip install -r requirements.txt
2. Start the API Server
python chat_api.py

Server will run at http://localhost:5000

3. Test Locally

Open index.html in your browser or use:

python -m http.server 8000

Then visit http://localhost:8000

4. Deploy

See chat/README.md for deployment options:

  • Frontend: GitHub Pages, Vercel, or Netlify
  • Backend: Render, Railway, or same server as bot
5. Configure in Telegram

After deployment, configure the Mini App in @BotFather
